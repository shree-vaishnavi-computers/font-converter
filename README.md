# Shree Vaishnavi Computers - Hindi Font Converter
आधिकारिक सरकारी व निजी दस्तावेज़ों के लिए **Devlys 010 / Kruti Dev** और **Unicode (Mangal)** फ़ॉन्ट कनवर्टर।
🌐 **लाइव वेबसाइट:** [यहाँ क्लिक करके कनवर्टर खोलें](https://shree-vaishnavi-computers.github.io/font-converter/)
### प्रमुख विशेषताएँ:
- **Two-Way Conversion:** Devlys 010 से Unicode और Unicode से Devlys 010 में 100% सटीक मैपिंग।
- **Voice Typing Support:** हिंदी में बोलकर सीधे टाइप और कन्वर्ट करने की सुविधा।
- **Live Statistics:** वर्ण (Characters), शब्द (Words), पैराग्राफ और वाक्यों की लाइव गणना।
- **Font Preview:** Devlys 010 फॉन्ट व्यू को सीधे ब्राउज़र में देखने और .TTF फ़ाइल लोड करने का विकल्प।
